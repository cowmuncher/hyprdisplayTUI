# hyprdisplay

🖥️ A simple TUI for managing display settings in Hyprland

## Features

- View connected monitors and their current configuration
- Adjust resolution, refresh rate, and scale
- Change monitor position/layout
- Manage projecting/mirroring
- Enable/disable displays
- Apply changes instantly

## Installation

```bash
git clone https://github.com/cowmuncher/hyprdisplaytui.git
cd hyprdisplayTUI
# build/install blablabla
```

## Usage

```bash
hyprdisplayTUI blablabla
```

Navigate with arrow keys (hjkl), select a monitor, and adjust settings. Changes are applied live through Hyprland's IPC.

## Requirements

- Hyprland
- `hyprctl` available in `$PATH`
